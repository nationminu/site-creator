# 마감 품질 체크리스트 (완성도)

> 기준 문서. 요구사항에 명시되지 않아도 "완성된 사이트"라면 갖춰야 할 마감 항목이다.
> **기능 추가가 아니다** — 이미 승인된 화면·기능이 정상·예외 상황에서 완결되게 만드는 항목이다. 새 동작(팝업·위젯·추적 스크립트 등)은 여기 없으며 `CLAUDE.md` §8 "기능 결정권"을 따른다.

| 쓰는 팀 | 시점 | 하는 일 |
|---|---|---|
| planner | P2 | 해당 항목을 `REQ-N`/`REQ-C`·화면정의서 "예외·상태"에 반영 (해당 없음은 사유) |
| designer | P3 | 상태·예외 화면 명세와 목업 (오류·빈 상태·404 등) |
| developer | P4 | 구현, 자체 점검 |
| qa | P5 | 테스트 케이스 "비기능 점검"에 포함해 확인 |

## 1. 페이지·메타
- [ ] 404 페이지 (사이트 톤 유지, 홈·주요 메뉴로 돌아가는 링크) · 백엔드가 있으면 500 오류 페이지
- [ ] 페이지별 고유 `<title>`·description, 브라우저 탭 제목 형식 통일 (예: `페이지명 | 회사명`)
- [ ] 파비콘(여러 크기)·apple-touch-icon, OG 이미지(1200×630)·OG 제목·설명 — 카카오톡·네이버 공유 미리보기
- [ ] `lang="ko"`, canonical URL, sitemap.xml·robots.txt (프리뷰 환경은 noindex)

## 2. 상태·예외
- [ ] 폼: 입력 검증 메시지(필드별), 전송 중(중복 제출 방지), 성공·실패 안내, 필수 동의 미체크 안내
- [ ] 목록: 빈 상태(게시물 없음), 페이지네이션 끝, 검색 결과 없음(검색이 승인된 경우)
- [ ] 이미지: 로딩 전 자리(레이아웃 밀림 없음), 이미지 없음·깨짐 대체
- [ ] 긴 텍스트: 긴 제목·이메일·URL 줄바꿈, 말줄임 규칙, 한글 단어 단위 줄바꿈(`word-break: keep-all`)
- [ ] 외부 링크: 새 창 여부 규칙 통일, 새 창이면 표시·`rel="noopener"`
- [ ] 전화·이메일·주소: 모바일에서 `tel:`·`mailto:`·지도 앱 연결

## 3. 반응형·환경
- [ ] 360 미만(320) 폭에서도 가로 스크롤 없음, 1920 이상 대화면에서 콘텐츠 폭 제한
- [ ] 가로 모드(모바일), 브라우저 확대 200%에서 내용 손실 없음
- [ ] 인쇄 시 내비게이션·배너 숨김(주요 정보 페이지)
- [ ] `prefers-reduced-motion` 대응

## 4. 문구 (톤앤매너)
- [ ] 화면정의서의 톤앤매너 가이드(문체·높임말·용어 사전)와 일치, 같은 대상에 같은 용어
- [ ] 맞춤법·띄어쓰기, 숫자·날짜·전화번호 표기 형식 통일
- [ ] 버튼·링크 문구가 동작을 설명 ("더보기" 남발 금지, 접근 가능한 이름)
- [ ] 사이트 안 `[TBD`·Lorem ipsum·플레이스홀더 0건

## 5. 운영 대비
- [ ] 저작권 표기 연도, 푸터 법적 고지 링크 (`kr-web-checklist.md` §3)
- [ ] 관리자 기능이 있으면: 로그인 실패 안내, 세션 만료 처리, 삭제 확인, 업로드 용량·형식 안내
