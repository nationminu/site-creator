# 국내 홈페이지 실무 체크리스트

> 기준 문서. 콘텐츠 수급, PM 사전 준비, 법적·필수 고지, 검색엔진 등록에 관한 공통 체크리스트다.
> 법률 판단이 아니라 **누락 방지용 점검 목록**이다. 적용 여부는 고객 사업 형태에 따라 다르므로 `pm/requests/QNA.md`에 질문(`Q-xxx`)으로 등록해 확인받고, 법률 검토가 필요하면 고객 측 전문가 확인을 권고한다.

## 1. 콘텐츠 수급 (P1 계획 → 배포 전 완료)
홈페이지 일정 지연의 가장 흔한 원인은 고객 원고·사진·로고 수급 지연이다.

| 항목 | 내용 |
|---|---|
| 수급 목록 | 로고(벡터), 대표 이미지·제품/시설 사진, 회사 소개·연혁·조직, 서비스·제품 설명, 연락처·주소·지도, 인증·수상, SNS 계정, 법적 고지 문안 |
| 계획 | pmo가 P1 계획서 "콘텐츠 수급 계획"에 자료·제공자·**기한**·상태를 적는다. 기한은 해당 자료가 필요한 단계 시작 전으로 잡는다 (로고·브랜드 → P3, 원고·사진 → P4 구현 중반) |
| 추적 | planner는 요구사항 "고객 확인 필요 사항"과 REQ-C의 확보 상태를, pmo는 STATUS "TBD·콘텐츠 수급" 건수를 매 게이트마다 갱신한다 |
| 배포 조건 | **배포 전 사이트 안의 `[TBD` 0건.** 남아 있으면 PM이 항목별로 예외 승인(임시 문구·숨김 처리)해야 G7·배포 진행 |

## 2. PM 사전 준비 항목 (P1에서 기한 확정 → 늦어도 P7 착수 전)
| 항목 | 필요 시점 | 비고 |
|---|---|---|
| 도메인 (보유 여부·등록처·DNS 관리 권한) | P7 | 신규 등록·이전은 시간이 걸린다 |
| 호스팅 계정 (업체·상품, 관리자 접근) | P4 (kr-shared는 기술 설계 시 환경 확인) | 공유 호스팅은 PHP·DB 버전 확인 필요 |
| 폼·메일 발송 서비스 계정 | P4 | 외부 폼 서비스, SMTP·메일 API |
| 분석 도구 (GA4 등) | P7 | 개인정보처리방침에 반영 |
| 검색엔진 등록 계정 (§4) | P7 배포 직후 | |
| 기타 외부 서비스 (지도 API 키, 결제 PG, 예약) | P4 | 키 값은 `.env`·PM 보관, 문서에 기록 금지 |

## 3. 법적·필수 고지 (planner가 REQ-C로 관리)
| 항목 | 필요한 경우 | 비고 |
|---|---|---|
| 개인정보처리방침 (푸터 링크) | 문의 폼·회원가입·예약 등 **개인정보를 수집**하는 경우, 분석·쿠키 도구 사용 시 기재 | 수집 항목·목적·보유 기간·위탁·파기·책임자·열람 청구 방법. 문안은 고객 제공 또는 고객 확인 |
| 수집·이용 동의 (폼 내) | 폼에서 개인정보를 받는 경우 | 필수 체크 항목, 처리방침 링크 |
| 이용약관 | 회원가입·게시판 등 회원 서비스가 있는 경우 | |
| 사업자 정보 표시 (푸터) | 통신판매(온라인 판매·결제)가 있는 경우 | 상호, 대표자, 주소, 전화, 사업자등록번호, 통신판매업 신고번호 등 |
| 이메일 무단수집 거부 문구 | 관행적으로 표기하는 경우가 많음 (고객 선택) | |
| 저작권·이미지 출처 | 외부 이미지·폰트 사용 시 | `design/assets/SOURCES.md`와 일치 |
| 웹 접근성 | 기본 품질 기준(WCAG 2.1 AA / KWCAG 2.2) | 공공·법인 등은 접근성 의무 대상일 수 있음 — 고객 확인 |

## 4. 검색엔진 등록 (devops — 배포 후 체크리스트·운영 가이드)
| 항목 | 내용 | 담당 |
|---|---|---|
| 네이버 서치어드바이저 | 사이트 소유 확인(메타 태그 또는 HTML 파일), `sitemap.xml` 제출, `robots.txt` 확인, 수집 요청 | 계정 로그인·소유 확인은 **PM 조치**, 확인용 메타 태그·파일 반영은 developer(`to-developer` 티켓) |
| Google Search Console | 소유 확인, sitemap 제출 | 위와 같음 |
| 다음 웹마스터도구 등 기타 | 고객 요청 시 | 위와 같음 |
| 대표 이미지·설명 (OG) | 네이버·카카오톡 공유 미리보기 확인 | qa 스모크 테스트에서 확인 |
