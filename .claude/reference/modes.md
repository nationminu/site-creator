# 진행 모드 (standard / lite)

> 기준 문서. 진행 모드에 관한 규칙은 이 파일에만 정의하고, 다른 문서는 이 파일을 참조한다.

kickoff 때 정해 `{PROJECT}/pm/STATUS.md`의 "진행 모드"에 기록한다. **기본값은 `lite`** 이며, `standard`는 PM이 `/kickoff … --standard`로 시작하거나 전환을 지시할 때만 쓴다. 진행 중 변경은 PM 지시로만 하고 STATUS.md "예외 기록"에 남긴다. STATUS에 항목이 없으면 `lite`로 본다.

규모가 큰 프로젝트(회원·결제·외부 연동 다수, `react-spring` 예상, 10페이지 초과, 다수 이해관계자 등)는 pmo가 P1 계획서·G1 게이트 문서에 `standard` 전환을 **권고**한다(전환은 PM 결정).

## 차이

| 항목 | standard (대규모·고위험) | lite (**기본**) |
|---|---|---|
| 교차 검토자 | `CLAUDE.md` §2 단계표의 검토자 전원 | 산출물별 **주 검토자 1명** (아래 표) |
| 리뷰 라운드 상한 | 3라운드 | 2라운드 (초과 시 PM 결정) |
| 교차 검토 모델 | 세션 기본 모델 | **`sonnet`** — 검토 호출에만. 작성·반영·구현·결함 수정·배포 등 작업 호출은 세션 기본 모델. **단, 품질 핵심 검토는 기본 모델**: P3 목업 검토, P4 디자인 QA, P5 테스트 결과 검토, `/suggest`의 디자인(이미지) 검토 |
| P3 컨셉 시안 | 2~3안 | 1~2안 (PM 선택 절차는 유지) |
| 게이트 문서 | 전체 양식 | **간소판** — `templates/docs/pm/gate.md`의 §1 산출물 점검·§3 체크리스트·§6 권고·§7 PM 결정만 작성, 나머지 절은 해당 사항이 있을 때만 한 줄 |
| P6 중간보고 | 수행 (G6) | **생략 가능** — G5 보고에서 PM이 생략을 승인하면 STATUS에 `➖ 생략`, G6 문서·태그 없음. 이후 "G6"를 요구하는 곳은 "G5 + 생략 승인 기록(STATUS 예외 기록)"으로 대체 |
| P1 계획서 | 전체 양식 | 간소판 — 템플릿 상단 "lite 작성 범위"(1~2쪽) |
| P8 최종 보고서 | 전체 | 요약판(1~2쪽). 운영 가이드·회고는 유지 |

**모드와 무관하게 유지**: (백엔드가 있는 프리셋의) P4 보안 코드 리뷰 — 기본 모델,  모든 게이트 PM 승인(lite의 G6 생략 제외), Must 지적 해소, `CLAUDE.md` §6 품질 기준, P5 Critical·Major 0건, **P7 PM 배포 승인**, 배포 전 `[TBD` 0건(또는 PM 예외 승인), §8 안전 규칙, §9 커밋 규칙.

## lite 주 검토자

작성자와 검토자가 같아지지 않도록 **산출물 단위**로 정한다.

| 단계 | 대상 산출물 | 주 검토자 |
|---|---|---|
| P1 | 계획서 | `planner` (고객 요청 누락·범위 — 기술·호스팅은 devops 사전 의견이 다룸) |
| P2 | 요구사항·IA·화면정의서 | `developer` |
| P3 | 디자인 시스템·페이지 디자인·목업 | `developer` |
| P4 | 기술 설계 | `devops` |
| P4 | 구현 (디자인 QA — 스크린샷 기반) | `designer` |
| P5 | 테스트 결과 | `developer` |
| P7 | 배포 계획 | `developer` |
| P8 | 최종 보고서 | `devops` |
| P8 | 운영 가이드 | `developer` |

## lite 검토 모델 예외
- 위 표의 "품질 핵심 검토"는 처음부터 세션 기본 모델로 호출한다(이미지 비교·최종 품질 판정).
- 그 밖의 sonnet 검토가 다음 중 하나에 해당하면 해당 검토자만 세션 기본 모델로 **1회 재검토**하고 그 결과를 따른다. 재검토 사실은 리뷰 파일 끝에 기록한다.
  - 판정이 Must를 근거 없이 남발하거나 대상 문서를 잘못 읽은 것으로 보일 때
  - Owner가 Must 지적에 타당한 반론을 제시해 판단이 갈릴 때
