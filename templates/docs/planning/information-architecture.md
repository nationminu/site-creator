## 7. 리뉴얼 대응 (기존 사이트가 있을 때)
### 7.1 URL 리다이렉트 맵
기존 URL이 검색 결과·외부 링크에 남아 있으므로 **모든 주요 기존 URL을 새 URL로 301 리다이렉트**한다. 기존 sitemap·주요 메뉴·검색 노출 페이지에서 수집한다(수집 방법과 일자 기록).

| 기존 URL | 새 URL (SCR) | 방식 (301 / 없어짐 → 상위 페이지) | 비고 |
|---|---|---|---|
