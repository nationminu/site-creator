## 4. 일정 — 오픈일 역산
에이전트 작업 시간보다 **고객 응답·자료 수급·PM 승인 대기**가 기간을 좌우한다. 오픈 목표일에서 거꾸로 계산한다.

**일정 전제**
| 항목 | 값 |
|---|---|
| 오픈 목표일 | |
| 고객 검토·응답 기간 (회당) | 예: 3영업일 |
| PM 게이트 승인 응답 | 예: 1영업일 |
| 버퍼 | 예: 전체의 15~20% |

| 단계 | 주요 작업 | Owner | 에이전트 작업 (예상) | 대기 요인 (고객·PM·외부) | 시작 | 종료 | 마일스톤 |
|---|---|---|---|---|---|---|---|
| P1 계획 | 요청 분석, 계획 수립 | pmo | | 고객 질문 답변 | | | G1 |
| P2 기획 | 요구사항, IA, 화면정의 | planner | | 제안 기능 결정, 원고 일부 | | | G2 |
| P3 디자인 | 시안 → PM·고객 선택 → 디자인 시스템·목업 | designer | | 시안 선택·피드백 | | | 시안 선택, G3 |
| P4 개발 | 기술 설계 → 작업 단위 구현 → 자체 점검 | developer | | 원고·사진 수급, 계정 준비 | | | G4 |
| P5 검증 | 테스트 → 결함 수정 → 프리뷰 확인 | qa | | 프리뷰 피드백 | | | G5 |

| P7 배포 | 배포 계획 → PM 승인 → 배포 → 스모크 | devops | | 도메인·DNS, 배포 승인 | | | 오픈, G7 |
