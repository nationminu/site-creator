### 4.1 DNS 전환 체크리스트 (변경이 있을 때)
**기존 레코드 (변경 전 전체 기록 — 메일 레코드 유지)**
| 유형 | 이름 | 값 | TTL | 변경 여부 |
|---|---|---|---|---|
| MX | @ | | | **유지** |
| TXT (SPF) | @ | | | **유지** |
| A / CNAME | @ · www | | | 변경 |

- [ ] 전환 24~48시간 전 TTL 낮춤 (PM 조치)
- [ ] 네임서버 이전이면 모든 레코드를 새 곳에 먼저 복제
- [ ] 전환 후 전파 확인 (`nslookup`·`dig`)
- [ ] HTTPS 발급 확인
- [ ] 회사 메일 수신 확인 (PM 테스트 메일)
