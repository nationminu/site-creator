# inbox — 제안 자료 넣는 곳

PM·고객이 제안하는 **시안 캡처, 참고 이미지, 기획 문서, 원고·사진**을 이 폴더에 넣고 `/suggest`로 알려 주세요.

```text
/suggest 메인 상단을 첨부 캡처처럼 영상 배경으로 바꾸고 싶다는 고객 의견 (inbox/main-hero-ref.png)
```

- 접수되면 파일은 `pm/requests/attachments/SUG-{번호}/`로 옮겨지고 이 폴더는 비워집니다.
- 채팅에 바로 붙여 넣은 이미지는 파일로 저장되지 않습니다. 원본을 보관·재사용해야 하면 이 폴더에 파일로 넣어 주세요.
- 고객이 준 사진·로고·폰트는 **사용 권리**(고객 소유·라이선스)를 함께 알려 주세요.
- 비밀번호·계정 정보·개인정보가 담긴 파일은 넣지 마세요.
